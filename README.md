# Task Manager

A simple command-line Task Manager built with Python.

## Features

- Add tasks
- View tasks
- Delete tasks
- Edit tasks
- Save tasks to a text file
- Load tasks from a text file
- Handle invalid user input
- Handle tasks that do not exist

## Technologies

- Python
- Functions
- Lists
- File handling
- Modules
- Exception handling
- Git and GitHub
